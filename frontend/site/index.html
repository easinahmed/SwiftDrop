Everything a downloader should do

Copy a link, press ⌃⌥D

Copy any download or video link, press the shortcut (Ctrl+Alt+D on Windows) or click the Send to SwiftDrop bookmark, and an IDM-style pop-up appears — no extension to install. Or paste hundreds of links at once.

4K that opens in QuickTime

MP4 downloads use H.264 or AV1 with AAC audio, and convert with your Mac's media engine when needed.

No more stalls at 99%

Several connections per file, and any connection that slows to a crawl is reopened automatically.

Picks up where it stopped

Pause, quit, even a crash — downloads resume from the bytes already on disk, never from zero.

Video sites and playlists

YouTube, Vimeo, SoundCloud, podcasts and many more public sources, with quality and format choices.

Safe by design

Files are marked as downloaded from the internet, and anything that can run code asks before it opens.

Install in a minute

Mac

  1. Download the DMG.
  2. Drag SwiftDrop into Applications.
  3. Right-click → Open the first time (the app isn't signed with an Apple Developer ID yet).

Windows

  1. Download SwiftDrop-Setup.exe.
  2. If SmartScreen appears, click More info → Run anyway (the installer isn't code-signed yet).
  3. Install and launch SwiftDrop from the Start menu.
